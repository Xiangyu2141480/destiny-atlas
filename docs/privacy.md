# 隐私说明

Destiny Atlas 默认是纯静态、客户端计算应用：

- 不要求账户，不包含分析、广告或追踪 SDK。
- 出生日期、时间、城市、MBTI 与生成报告不会由应用代码上传。
- 页面刷新后输入与报告不会写入 Local Storage、Cookie 或 IndexedDB。
- JSON 导出由浏览器在本机创建；打印/PDF 由浏览器打印功能处理。
- 字体使用本机系统字体；背景、星轨与流星由本地 CSS / SVG 绘制，不向外部字体或素材服务发起请求。

GitHub Pages、Vercel 或其他托管平台可能保留常规访问日志；这由部署者的隐私政策控制，不是本项目计算引擎的数据传输。

使用 CLI 时，输入和输出文件完全由执行者管理。请避免把含个人出生资料的样例、日志或导出报告提交到公开仓库。

未来如接入地理编码、AI 或其他外部服务，必须另行取得明确同意、最小化发送字段，并在 UI 显示接收方和用途；当前版本未实现这些外部调用。
