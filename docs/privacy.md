# 隐私说明

Destiny Atlas 的报告生成仍在本地浏览器或 CLI 内完成，不需要账户，不包含广告、追踪或分析 SDK。输入和报告只在内存中保留，刷新后不会写入 Local Storage、Cookie 或 IndexedDB。JSON 与打印由用户主动操作，在本机生成。

阅读模式可通过 URL 的 `view=summary` 或 `view=detailed` 分享；只有版本选项进入 URL，不包含出生资料、关注领域或生成结果。切换版本复用内存中的报告，不发起网络查询。打印保存当前可见版本；JSON 导出仍包含完整报告，请自行确认分享对象。

## 可选联网城市查询

只有在“联网查找更多城市”中点击“联网搜索”或按 Enter 时，前端才向 `https://geocoding-api.open-meteo.com/v1/search` 发出请求。

- 请求只包含城市关键词、结果数量、语言与格式。
- 不发送姓名、出生日期、出生时间、MBTI 或报告。
- fetch 使用 `credentials: omit` 与 `referrerPolicy: no-referrer`。
- 外部服务仍能收到请求 IP 与常规网络元数据。不要在城市关键词中填写其他个人信息。
- 用户核对结果并选择后，才把经纬度和 IANA 时区作为自定义地点参与本地计算。导出保留来源、许可及是否修改的标记。
- 失败、限流、超时或未查询时，均可继续使用离线地点与手动坐标。

## 外部参考资料

“联网查证计算方法与资料”的链接会打开对应第三方网站或搜索引擎。链接使用固定的方法查询，不包含用户出生信息、报告、个人年或 MBTI；不自动抓取网页或执行网页内容。

站点使用系统字体、本地 CSS / SVG 及本地人物插画，不向外部字体或素材服务发送请求。GitHub Pages 等托管方可能保留常规访问日志，由其隐私政策管理。

## 许可与使用范围

Open-Meteo 地理编码服务的公开条款、非商业限制及数据许可见其官方项目说明与界面来源链接。代码许可与在线数据许可分别适用；本项目不会要求用户提供 API Key 或账号。

使用 CLI 时输入、输出文件由执行者自行管理。不要把真实个人出生资料、报告或凭证提交到公开仓库。
